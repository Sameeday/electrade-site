# Electrade - Electronics E-Commerce Website

**Live Site:** [Coming soon - will be added after Vercel deployment]

## About
Electrade is an e-commerce website for electronics products in Pakistan, featuring:
- 📱 LED TVs, Air Conditioners, Refrigerators, Washing Machines
- 🏠 Home & Kitchen Appliances
- 🔌 Power Tools & Commercial Products
- 🛒 Shopping cart and checkout system
- 💬 WhatsApp integration for customer support

## Technology
- **Frontend:** Plain HTML, CSS, Vanilla JavaScript
- **Backend:** Supabase (Database & Authentication)
- **Payment:** Cash on Delivery (COD)
- **Hosting:** Vercel

## Project Structure
```
Electrade-site/
├── index.html          # Homepage
├── cart.html           # Shopping cart
├── checkout.html       # Checkout page
├── product.html        # Product details
├── category.html       # Dynamic category pages
├── site.css            # Main styles
├── site-mobile.css     # Mobile-responsive styles
├── supabase-client.js  # Database connection
├── site-nav.js         # Navigation system
└── images/             # Product images
```

## Features
- ✅ Responsive design (desktop & mobile)
- ✅ Dynamic product catalog from Supabase
- ✅ Real-time shopping cart
- ✅ Secure checkout with order tracking
- ✅ Category filtering and product search
- ✅ WhatsApp customer support integration

## Setup
This is a static website - simply open `index.html` in a browser to view locally, or deploy to any static hosting service.
